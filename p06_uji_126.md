Dokumen ini berisi daftar skenario uji positif dan negatif untuk membuktikan bahwa batasan (constraints) dan aturan bisnis pada basis data berjalan dengan baik.

## Tabel Skenario Uji

| Kode Uji | Jenis Uji | Kasus / Masukan | Harapan Sistem | Hasil Nyata / Galat | Status |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **UJ-01** | Positif | Menambah data pasien baru yang valid | Diterima oleh server | 1 baris berhasil ditambahkan | **LULUS** |
| **UJ-02** | Positif | Menambah obat baru dengan stok awal 10 | Diterima oleh server | 1 baris berhasil ditambahkan | **LULUS** |
| **UJ-03** | Negatif | Mengubah stok obat menjadi negatif (`stok = -5`) | Ditolak constraint CHECK | ERROR 4025: Check constraint 'ck_obat_stok' is violated | **LULUS** |
| **UJ-04** | Negatif | Memasukkan NIK pasien yang sudah kembar/duplikat | Ditolak constraint UNIQUE | ERROR 1062: Duplicate entry for key 'uq_pasien_nik' | **LULUS** |
| **UJ-05** | Negatif | Mengisi detail resep dengan jumlah obat 0 (`jumlah_obat = 0`) | Ditolak constraint CHECK | ERROR 4025: Check constraint 'ck_detail_jumlah' is violated | **LULUS** |
| **UJ-06** | Negatif | Membuat pemeriksaan dengan `id_dokter` yang tidak terdaftar (misal: 99) | Ditolak Foreign Key | ERROR 1452: Cannot add or update a child row | **LULUS** |
| **UJ-07** | Negatif | Menjalankan `UPDATE obat SET harga_jual = 5000;` tanpa klausul WHERE saat mode aman aktif | Ditolak mode aman | ERROR 1175: You are using safe update mode | **LULUS** |
| **UJ-08** | Negatif | Menghapus data dokter yang sudah memiliki relasi riwayat rekam medis | Ditolak Foreign Key | ERROR 1451: Cannot delete or update a parent row | **LULUS** |
| **UJ-09** | Positif | Menghapus pemeriksaan, lalu memastikan detail resep ikut terhapus otomatis | Diterima (Cascade) | Data rincian resep ikut terhapus otomatis | **LULUS** |
| **UJ-10** | Gagal* | Memasukkan jumlah obat yang melebihi batas stok tersedia (Aturan bisnis lintas baris) | *Harus ditolak* | *Diterima server (karena batas stok belum dicek CHECK baris tunggal)* | **GAGAL* (Utang Desain Modul 14)** |

*\*Catatan UJ-10:* Pengujian UJ-10 sengaja dibiarkan gagal karena validasi stok melebihi batas memerlukan *Trigger* atau logika pemrograman di aplikasi, yang akan diselesaikan pada Modul 14.
